Um conjunto de permissões atribuído a usuários — define o que cada um pode ver e fazer no sistema.

Uma função sem nenhuma permissão atribuída não dá acesso a nada administrativo pra quem a tem.

Permissões marcadas como administrativa afetam todos os usuários com a função — removê-las pede confirmação extra.

Padrão para novos colaboradores — já vem marcada pra quem é convidado; dá pra desmarcar no cadastro.

Administrador — permissões gerenciadas pelo sistema, não editáveis aqui.
