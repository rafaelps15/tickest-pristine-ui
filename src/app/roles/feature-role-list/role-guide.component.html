Um conjunto de permissões atribuído a usuários — define o que cada um pode ver e fazer no sistema.

As funções vêm da configuração do sistema: aqui você ajusta as permissões de cada uma pelo "⋮" da linha.

Uma mudança vale na hora para todos os usuários com a função. Uma função sem nenhuma permissão não libera nada pra quem a tem.

Permissões marcadas como administrativa dão poder de gestão — removê-las pede confirmação extra.

Padrão para novos colaboradores — já vem marcada pra quem é convidado; dá pra desmarcar no cadastro.

Administrador — permissões gerenciadas pelo sistema: dá pra consultar, não alterar.
