• Ativo Pode entrar no sistema normalmente.
  • Inativo Login bloqueado — pode ser reativado a qualquer momento.
  • Convite pendente Ainda não ativou a conta pelo link do e-mail. Se o convite venceu, use "Reenviar convite" no ⋮.

Aparecem como badges em índigo, ou na cor escolhida para cada uma na tela Funções, onde também são cadastradas. Como não há um conjunto fixo, não há legenda aqui.

Clicar numa linha (ou no nome, pelo teclado) abre o painel de informações daquele usuário, com os mesmos atalhos do menu ⋮ (editar, atribuir funções, ativar ou desativar).

Marcar o checkbox é pra ação em lote (ex.: desativar vários de uma vez) — são seleções independentes, uma não afeta a outra.

O termo de busca não fica salvo no link (por privacidade) — recarregar a página limpa a busca, mas mantém os outros filtros.
